# photo-matching Specification

## Purpose
사용자가 선택한 사진 한 장을 브라우저 안에서만 분석하여, 동물의 숲 캐릭터 도감(566종) 중 가장 닮은 캐릭터 TOP 5를 유사도와 함께 보여주는 핵심 기능을 정의한다.

## Requirements

### Requirement: 사진 선택과 입력 검증
The system SHALL JPG·PNG·WebP 형식, 12MB 이하, 4,000만 픽셀 이하의 이미지 파일만 분석 대상으로 받아들이고, 조건을 벗어나는 파일에는 이유를 설명하는 한국어 오류 메시지를 보여야 한다(MUST).

#### Scenario: 지원 형식의 정상 파일
- **WHEN** 사용자가 10MB 이하의 JPG 사진을 선택하면
- **THEN** 파일이 수락되고 분석을 시작할 수 있는 상태가 된다

#### Scenario: 지원하지 않는 형식
- **WHEN** 사용자가 HEIC 등 지원하지 않는 형식의 파일을 선택하면
- **THEN** 분석을 시작하지 않고 지원 형식을 안내하는 오류 메시지를 보여준다

#### Scenario: 크기 초과
- **WHEN** 12MB를 초과하거나 4,000만 픽셀을 초과하는 이미지를 선택하면
- **THEN** 분석을 시작하지 않고 제한을 안내하는 오류 메시지를 보여준다

### Requirement: 브라우저 내 분석 (프라이버시)
The system SHALL 선택된 사진의 전처리와 임베딩 계산을 모두 사용자의 브라우저 안에서 수행해야 하며, 사진 데이터 또는 그 파생물(픽셀, 임베딩 벡터)을 어떤 서버로도 전송하면 안 된다(MUST NOT).

#### Scenario: 분석 중 네트워크 요청
- **WHEN** 사진 분석이 진행되는 동안 네트워크 요청을 관찰하면
- **THEN** 모델·도감 등 정적 자산 다운로드 외에 사진 데이터가 포함된 요청이 존재하지 않는다

### Requirement: 사진 전처리
The system SHALL 분석 전에 사진을 흰 배경에 합성하고 가로·세로 최대 512px로 축소해야 하며, 사용자 사진과 도감 이미지에 동일한 전처리·모델·버전을 사용해야 한다(MUST).

#### Scenario: 투명 배경 PNG
- **WHEN** 투명 배경을 가진 PNG를 선택하면
- **THEN** 흰 배경에 합성된 상태로 전처리되어 분석된다

### Requirement: 유사도 계산과 TOP 5 결과
The system SHALL 사진의 임베딩 벡터와 미리 계산된 566개 캐릭터 벡터의 코사인 유사도를 비교하여, 유사도가 높은 순서로 상위 5개 캐릭터를 이름·이미지·유사도와 함께 보여야 한다(MUST).

#### Scenario: 정상 분석 완료
- **WHEN** 유효한 사진의 분석이 완료되면
- **THEN** 닮은 순서대로 5개 캐릭터가 각각의 이름, 도감 이미지, 유사도 수치와 함께 표시된다

#### Scenario: 도감 이미지로 자기 자신 찾기
- **WHEN** 도감에 포함된 캐릭터의 원본 이미지를 그대로 입력하면
- **THEN** 해당 캐릭터가 1위로, 가장 높은 유사도로 표시된다

### Requirement: 비교 범위 선택
The system SHALL 비교 대상을 전체(566)·일반 주민(490)·모여봐요 주민(417)·특수 캐릭터(76) 중에서 선택할 수 있게 해야 하며, 결과는 선택된 범위 안에서만 계산되어야 한다(MUST).

#### Scenario: 특수 캐릭터로 범위 제한
- **WHEN** 비교 범위를 "특수 76개"로 선택하고 분석하면
- **THEN** TOP 5가 모두 특수 캐릭터 중에서만 선정된다

### Requirement: 도감 열람
The system SHALL 분석과 별개로 도감의 캐릭터 목록을 페이지 단위로 열람할 수 있게 해야 한다(MUST).

#### Scenario: 도감 페이지 이동
- **WHEN** 도감 목록에서 다음 페이지로 이동하면
- **THEN** 다음 캐릭터 묶음이 이름·이미지와 함께 표시된다

### Requirement: 모델 로딩 상태 안내
The system SHALL 첫 분석 시 모델 가중치 다운로드와 초기화가 필요함을 사용자에게 진행 상태로 보여야 하며, 모델 로딩 실패 시 재시도 가능함을 안내하는 오류 메시지를 보여야 한다(MUST).

#### Scenario: 첫 방문 분석
- **WHEN** 모델이 아직 다운로드되지 않은 상태에서 분석을 시작하면
- **THEN** 다운로드·초기화 진행 상태가 표시되고 완료 후 자동으로 분석이 이어진다

#### Scenario: 모델 로딩 실패
- **WHEN** 네트워크 문제로 모델 다운로드가 실패하면
- **THEN** 실패 원인과 재시도 방법을 안내하는 메시지가 표시된다

### Requirement: 실행 환경 요구사항 안내
The system SHALL 현재 브라우저가 분석을 실행할 수 없는 환경일 때(WebGPU 미지원 등) 분석을 조용히 실패시키지 않고, 지원 브라우저를 안내하는 메시지를 보여야 한다(MUST).

#### Scenario: WebGPU 미지원 브라우저
- **WHEN** WebGPU를 지원하지 않는 브라우저로 접속해 분석을 시도하면
- **THEN** 지원 환경을 안내하는 메시지가 표시된다
